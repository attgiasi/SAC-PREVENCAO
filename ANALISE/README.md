# SAC Prevenção

## Versão ativa

A versão ativa é a `V8`.

Arquivos carregados pelo favorito:

- `favorito-universal.bookmarklet.txt`
- `motor-sac-universal.js`
- `V8/sac-memory-v8.js`
- `V8/sac-tabulator-v8.js`
- `V8/sac-prevencao-v8.js`

O carregador universal aponta exclusivamente para a V8 e carrega os motores na ordem correta.

Também existe um bookmarklet separado dentro de cada pasta de versão, no formato `bookmarklet-vX.txt`, para testar cada versão isoladamente.

As pastas anteriores ficam apenas como histórico local. Elas não são carregadas, importadas ou executadas pela versão ativa.

Consulte `V8/README-PASSO-A-PASSO.md` para instalação, regras, memória e testes.
