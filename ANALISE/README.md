# SAC Prevenção

## Versão ativa

A versão ativa é a `V11`.

Arquivos carregados pelo favorito:

- `favorito-universal.bookmarklet.txt`
- `motor-sac-universal.js`
- `V11/loader-v11.js`
- motores `V11/sac-*.js`

O carregador universal aponta exclusivamente para a V11.33. O loader resolve a revisão mais recente publicada e só então carrega os motores na ordem correta.

## Versões mantidas

- `V10`: referência estável arquivada.
- `V11`: versão ativa do favorito universal.
- `V12`: versão de homologação, executada apenas pelo bookmarklet próprio.

Cada pasta possui um bookmarklet próprio, no formato `bookmarklet-vX.txt`, para testes isolados. O bookmarklet da V12 não altera o favorito universal.

As versões V1 a V9 foram removidas e não participam de nenhum carregamento.

Consulte `V11/README-PASSO-A-PASSO.md` para instalação, regras, memória e testes.
Para homologar a versão nova, consulte `V12/README-PASSO-A-PASSO.md`.
