# SAC Prevenção

## Versão ativa

A versão ativa é a `V9`.

Arquivos carregados pelo favorito:

- `favorito-universal.bookmarklet.txt`
- `motor-sac-universal.js`
- `V9/sac-memory-v9.js`
- `V9/sac-tabulator-v9.js`
- `V9/sac-prevencao-v9.js`

O carregador universal aponta exclusivamente para a V9.18 e carrega os motores na ordem correta.

## Versão de teste

A `V10` é uma versão de teste isolada. Ela não é carregada pelo favorito universal. Use `V10/bookmarklet-v10.txt` apenas para validar o novo motor imediato de LISTAS e a preparação do formulário do Tabulador antes de promover para produção.

Também existe um bookmarklet separado dentro de cada pasta de versão, no formato `bookmarklet-vX.txt`, para testar cada versão isoladamente.

As pastas anteriores ficam apenas como histórico local. Elas não são carregadas, importadas ou executadas pela versão ativa.

Consulte `V9/README-PASSO-A-PASSO.md` para instalação, regras, memória e testes.
